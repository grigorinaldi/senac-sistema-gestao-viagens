# Sistema de Agência de Viagens

## Status do projeto
Em desenvolvimento

## Tecnologias utilizadas
- Java
- Java Swing (interface gráfica)
- MySQL
- Git e GitHub
- Apache NetBeans

## Time de desenvolvedores
- Giovanni Rigo Rinaldi

## Objetivo do software
O sistema tem como objetivo auxiliar uma agência de viagens no controle de clientes, pacotes turísticos e reservas, permitindo o cadastro, consulta, edição e exclusão dessas informações de forma organizada.

## Funcionalidades do sistema
- Cadastro, listagem, edição e exclusão de clientes
- Cadastro, listagem, edição e exclusão de pacotes de viagem
- Registro e cancelamento de reservas
- Associação de clientes a pacotes por meio de reservas
- Persistência dos dados em banco de dados MySQL
